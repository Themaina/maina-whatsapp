# Marketplace listing copy (maina888)

**Name:** WhatsApp Business Cloud API
**Tagline:** Order updates on WhatsApp with approved templates, a two-way inbox and SMS fallback.
**Category:** Notifications / Customer support
**Price:** Free (MIT)
**Compatibility:** Botble CMS core 7.3.0+, PHP 8.2+, any theme; Ecommerce and SMS via Africa's Talking plugins optional

**Short description**
Send order confirmations, payment receipts and completion messages over the official Meta WhatsApp Business Cloud API, and reply to customers from an inbox inside Botble. See delivered and read receipts for every message, honour STOP/START automatically, and fall back to SMS when a number isn't on WhatsApp.

**Highlights**
- Order notifications mapped to Meta-approved templates, with a "View order" button
- Template sync from Meta with approval and variable checks
- Two-way inbox within WhatsApp's 24-hour window
- Sent, delivered, read and failed receipts with error reasons and resend
- Automatic STOP/START opt-out
- Optional SMS fallback through the free SMS via Africa's Talking plugin
- Signed webhook, encrypted credentials, queued sending with retries
- Developer API and events for your own notifications
